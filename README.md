# pptx-progress-deck

把你已有的 PowerPoint 转成**单文件网页课件**，并带上一套**多班教学断点标注系统**。

解决的是一个很具体的麻烦：

> 同一份 PPT 要给好几个班上课，各班进度不同步，每节课还经常讲不完。
> 隔几天回到某个班，**记不清上次讲到哪一页了**。

网页版能记住这件事 —— 打开课件就知道"这个班上次停在哪"，下课按一个键更新。

**还能直接在浏览器里导 PPT**：顶栏「导入PPT」选一个 `.pptx`，页面当场解析并渲染，不需要 Python 转换工具 —— 解析全程在浏览器完成。

## 一、装依赖

```bash
pip install -r requirements.txt
```

> ⚠️ `lxml` 必须 **6.0 以下**。python-pptx 1.0.2 与 lxml 6.x 不兼容，会报
> `AttributeError: 'list' object has no attribute 'has_ph_elm'`。
> requirements.txt 里已经锁好了。

## 二、转一个文件（最快）

```bash
python3 convert.py 第一讲.pptx --id L01 --name 导论 \
        --title "第一讲·导论：叙事与我们" \
        --course "叙事理论与实践" \
        --classes "导演2601,导演2602,导演（国际）2601"
```

得到一个 `L01-导论.html`，双击就能用。班级数量不限，逗号分隔即可；不写 `--classes` 就默认生成 8 个占位班（可在网页里改）。

## 三、转一整门课（推荐）

```bash
cp config.example.json config.json     # 改课程名、班级、讲次
python3 convert.py --config config.json
```

`config.json` 里写清楚班级和讲次：

```json
{
  "course": "叙事理论与实践",
  "course_id": "narrative",
  "classes": [
    { "id": "c1", "name": "导演2601" },
    { "id": "c2", "name": "导演2602" }
  ],
  "pptx_dir": "./pptx",
  "out_dir": "./web",
  "lectures": [
    { "id": "L01", "name": "导论",   "file": "第一讲·导论_课件.pptx",   "title": "第一讲·导论" },
    { "id": "L02", "name": "故事与话语", "file": "第二讲_课件.pptx",      "title": "第二讲·故事与话语" }
  ]
}
```

转完之后，每个网页**顶栏都有讲次下拉框**，可以直接跳到同一门课的其它讲次，班级和进度自动带过去。

> `course_id` 决定哪些网页共享进度：同一门课用同一个 id，换一门课换一个，互不干扰。

## 三·五、直接在浏览器里导入 PPTX（不需要转换）

产物 HTML 自带一个**浏览器端 PPTX 解析器**（`pptx-viewer`，Apache-2.0，打包后约 50 KB）：

1. 打开任意一个已生成的课件网页；
2. 点顶栏 **「导入PPT」**，选一个 `.pptx` 文件；
3. 页面当场解析、按课件 IR 渲染，断点 / 班级 / 备注系统照常可用。

导入后顶栏标题换成文件名，进度按新课件单独记录；刷新页面回到文件自带的内容（导入不持久化，数据跟文件走）。图表、SmartArt 等元素会降级跳过，完成后 toast 会提示跳过了哪些。

### 批量导入多个 PPTX → 一整门课（多讲次）

顶栏「导入PPT」支持**多选**：按住 <kbd>Ctrl</kbd>/<kbd>Shift</kbd> 一次选多个 `.pptx`，页面会按文件名排序逐个解析，合并成一整门课（每个 PPTX 成为一个讲次 L01/L02/…），第一个讲次自动打开。

- 导入完成后，**顶栏出现讲次下拉框**，直接切换讲次，不跳页面；
- 每个讲次的课件内容、编辑修改各自独立保存，切换时自动回存；
- 点「保存」下载的 HTML 里**包含全部讲次**，拷到别的电脑打开，讲次下拉照样能用；
- 班级和进度在讲次之间共享（同一门课同一批班）。

单选一个 PPTX 时行为不变（替换当前课件）；多选时才走合并流程。

需要重新打包导入器时（改了 `tools/pptx-import/src/`）：

```bash
cd tools/pptx-import && npm install && node build.mjs
```

重新 `convert.py` 生成产物即带上新导入器；未构建时按钮自动隐藏。

## 三·六、直接在浏览器里编辑（不需要重转）

产物 HTML 自带一个**精简编辑器**（G2=B 自研方案：借解析和渲染，编辑器自己写）：

1. 点顶栏 **「编辑」**（或按 <kbd>E</kbd>）进入编辑模式；
2. **点选**元素（橙色选择框 + 8 向白色手柄），**拖动**移动，**拖手柄**缩放；
3. **双击文本框**直接改字（段落、颜色等样式保留）；选中文字框后工具条的 **A− / 字号输入 / A+** 调节字号（8–300px）；
4. 点 **「加图片」** 选本地图片（png/jpg/gif/webp 等），自动转 dataURL 内嵌、按比例缩放到最长边 400px 插入当前页，可继续拖动/缩放/删除；
5. 选中图片后工具条出现 **「填充」**（等比留空白 / 铺满裁切 / 拉伸变形，三态循环）和 **「裁剪」**（进入裁剪模式后拖黄色虚线手柄调整边界、拖动平移裁剪区域，再点「裁剪」完成）；
6. <kbd>Delete</kbd> 删除、<kbd>Ctrl+D</kbd> 复制（+24px 偏移）、<kbd>Ctrl+Z/Y</kbd> 撤销 / 重做（最多 60 步）；
7. 改完点 **「保存」**，浏览器下载一个**更新后的单文件 HTML**——它就是你的新课件，里面内嵌了编辑后的课件内容（含图片 dataURL）**和上课进度**（班级、断点、备注），拷到别的电脑 / U 盘 / 微信发给自己，打开直接用，进度自动恢复，还能继续编辑。

编辑模式下翻页、断点、滚轮全部暂停，防止误操作；<kbd>Esc</kbd> 退出。**不部署、不联网**，编辑结果只存在于你下载的文件里（文件即文档：内容 + 进度都在文件内）。

> 换设备流程：A 电脑编辑 / 上课 → 点「保存」下载 HTML → 把这个 HTML 拷到 B 电脑 → 双击打开 → 课件内容和上课进度都在，继续用。无需账号、无需云端、无需安装。

> 说明：文本框与色块支持移动/缩放/改字/调字号/删除/复制；图片支持插入/移动/缩放/填充模式/裁剪/删除/复制；从 PPTX 导入的图片会自动转 dataURL 内嵌，保存后跨设备可用；表格可选中、移动、缩放、删除、复制，改字与单元格编辑后续补齐。

## 四、上课怎么用

### 打开就知道讲到哪

右下角弹出提示条：**「上次讲到 P12，下次继续 P13」**，点 **继续 ▶** 直接跳过去。8 秒后自动收成小条，不挡课件。

### 下课按一个键

| 情况 | 按键 | 断点 |
|---|---|---|
| 这页**没讲完**，下次重讲 | <kbd>S</kbd> | = 当前页 |
| 这页**讲完了**，下次往下 | <kbd>Shift</kbd>+<kbd>S</kbd> | = 当前页 + 1 |

### 看整体进度

<kbd>Esc</kbd> 打开总览：**灰色 = 已讲，橙框 +「▶继续」= 断点**。顶部可切换班级，看别的班讲到哪了。

### 全部快捷键

| 键 | 作用 |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> / 空格 / 滚轮 | 翻页 |
| <kbd>S</kbd> / <kbd>Shift+S</kbd> | 记断点 |
| <kbd>Esc</kbd> | 总览 |
| <kbd>N</kbd> | 写备注（可增删改，可选「全课程」或「仅本班」） |
| <kbd>C</kbd> | 切换班级 |
| <kbd>H</kbd> | 隐藏界面，全屏讲课时用 |
| <kbd>E</kbd> | 进入 / 退出编辑模式（编辑内：<kbd>Ctrl+Z</kbd> 撤销 · <kbd>Ctrl+Y</kbd> 重做 · <kbd>Ctrl+D</kbd> 复制 · <kbd>Delete</kbd> 删除 · <kbd>Esc</kbd> 退出） |

## 五、班级怎么自定义

三种方式，随便用哪个：

1. **转的时候指定**：`--classes "导演2601,导演2602,网新2601"`
2. **写在 config.json 里**：批量转换时所有讲次共用
3. **在网页里直接改**：按 <kbd>C</kbd> 打开面板 —— 双击改名字，点 **×** 删除，点 **＋** 添加

班级数量没有限制，页面里加几个都行。

## 六、换电脑怎么办

进度存在浏览器的 localStorage 里，**只在这台电脑的这个浏览器有效**。跨设备用这几招（点顶栏「备份」按提示走）：

**① 复制网址（最省事）**
第 4 步选「复制带进度网址」，网址被复制到剪贴板。这个网址**自带进度**，存成书签，在任意设备打开都是最新进度（网址里的数字每次记录都会自动更新）。

**② 导出 / 导入进度备份**
第 1 步确定 = 导出 json（含所有班进度 + 备注）；换电脑用第 3 步「导入」恢复。

**③ 工程数据（IR）——课件内容跟着文件走**
每个产物 HTML 里**内嵌了一份完整课件数据（IR）**：全部页面、形状、文字、样式、表格与图片都在里面。用第 2 步可导出为独立 `.json`，或第 3 步导入另一份工程数据（页面会按新数据**重新渲染**：换标题、改内容、增删页面都生效）。导入仅本次会话生效，刷新后回到文件自带的数据——数据永远跟文件走，这正是后续浏览器内编辑的基础。

> 少数电脑（如 Firefox 打开本地文件）会禁掉 localStorage，页面会提示你，这时用第①招照样能讲课。

## 七、还原度与限制

自动转换**不是像素级复刻**，保真度大约 85–95%：

| 元素 | 情况 |
|---|---|
| 纯色文本、色块、图片 | 基本一致，坐标 100% 还原 |
| 表格 | 行列内容都对，边框粗细可能有细微差别 |
| 渐变填充 | 降级为首个色标的纯色 |
| 艺术字 / 阴影 / 三维 | 降级为纯文本 |
| SmartArt / 图表 / 公式 | 差，建议改用图片 |

每次转换会打印需要人工核对的页码（有表格、渐变、疑似文字溢出的页面），对着原 PPT 扫一眼就行。

## 八、目录结构

```
pptx-progress-deck/
├─ convert.py              主入口（单个 / 批量转换）
├─ config.example.json     配置模板
├─ requirements.txt
├─ fixtures/
│  ├─ make_sample.py       生成测试课件 sample.pptx（封面/内容/表格）
│  └─ sample.pptx          验证用样例
├─ tools/
│  ├─ pptx2html.py         pptx → 中间层 JSON（IR，离线转换用）
│  ├─ render.py            JSON + 模板 → 单文件网页（内嵌 IR 与浏览器导入器）
│  ├─ deck_template.html   网页外壳 + 断点系统 + 运行时 IR 渲染器 + 浏览器内编辑器（全部功能都在这里）
│  ├─ pptx-import/         浏览器端 PPTX 导入器（pptx-viewer 打包，src/ 改后需 node build.mjs）
│  └─ selftest.py          浏览器端自测（需要 playwright）
├─ api_push.py            受限网络下用 Git Data API 推送（保留提交历史）
├─ examples/               界面截图
└─ build/                  转换产物 + 编辑器端到端验证脚本（verify_m2.py / verify_regress.py）
```

想改界面或加功能，基本只需要动 `tools/deck_template.html`。页面默认**用内嵌 IR 在浏览器里渲染**，`render.py` 的渲染逻辑与模板里的 `renderSlides()` 保持同构，改渲染细节要两处同步。

## 九、自测

```bash
pip install playwright && playwright install chromium
python3 tools/selftest.py                 # 基础 34 项
python3 build/verify_regress.py           # 阶段一/二回归（IR 渲染、断点、导出、导入）
python3 build/verify_m2.py                # 编辑器端到端（选择/移动/缩放/改字/撤销重做/删除/复制/保存持久化）
```

浏览器为 `chromium`（系统路径 `/usr/local/bin/chromium`），脚本内已指定。

## 十、常见疑问

**Q：一份课件能支持多少个班？**
A：不限。默认 8 个只是占位，config 里写几个就是几个，网页里也能随时加减。

**Q：多个班共用一份 HTML 会串吗？**
A：不会。进度是按班级 id 分开存的，切换班级时断点、总览标记都跟着变。

**Q：一门课十几个讲次，要开十几个文件吗？**
A：是的，每个讲次一个 HTML。但它们共享同一份班级配置和进度，顶栏下拉可互相跳转。

**Q：能离线用吗？**
A：能，完全离线。单个 HTML 文件，无 CDN 依赖、无网络字体，拷 U 盘就能讲。
