# pptx-progress-deck

把你已有的 PowerPoint 转成**单文件网页课件**，并带上一套**多班教学断点标注系统**。

解决的是一个很具体的麻烦：

> 同一份 PPT 要给好几个班上课，各班进度不同步，每节课还经常讲不完。
> 隔几天回到某个班，**记不清上次讲到哪一页了**。

网页版能记住这件事 —— 打开课件就知道"这个班上次停在哪"，下课按一个键更新。

## 一、装依赖

```bash
pip install -r requirements.txt
```

> ⚠️ `lxml` 必须 **6.0 以下**。python-pptx 1.0.2 与 lxml 6.x 不兼容，会报
> `AttributeError: 'list' object has no attribute 'has_ph_elm'`。
> requirements.txt 里已经锁好了。

## 二、转一个文件（最快）

```bash
python3 convert.py 第一讲.pptx --id L01 --name 导论 \
        --title "第一讲·导论：叙事与我们" \
        --course "叙事理论与实践" \
        --classes "导演2601,导演2602,导演（国际）2601"
```

得到一个 `L01-导论.html`，双击就能用。班级数量不限，逗号分隔即可；不写 `--classes` 就默认生成 8 个占位班（可在网页里改）。

## 三、转一整门课（推荐）

```bash
cp config.example.json config.json     # 改课程名、班级、讲次
python3 convert.py --config config.json
```

`config.json` 里写清楚班级和讲次：

```json
{
  "course": "叙事理论与实践",
  "course_id": "narrative",
  "classes": [
    { "id": "c1", "name": "导演2601" },
    { "id": "c2", "name": "导演2602" }
  ],
  "pptx_dir": "./pptx",
  "out_dir": "./web",
  "lectures": [
    { "id": "L01", "name": "导论",   "file": "第一讲·导论_课件.pptx",   "title": "第一讲·导论" },
    { "id": "L02", "name": "故事与话语", "file": "第二讲_课件.pptx",      "title": "第二讲·故事与话语" }
  ]
}
```

转完之后，每个网页**顶栏都有讲次下拉框**，可以直接跳到同一门课的其它讲次，班级和进度自动带过去。

> `course_id` 决定哪些网页共享进度：同一门课用同一个 id，换一门课换一个，互不干扰。

## 四、上课怎么用

### 打开就知道讲到哪

右下角弹出提示条：**「上次讲到 P12，下次继续 P13」**，点 **继续 ▶** 直接跳过去。8 秒后自动收成小条，不挡课件。

### 下课按一个键

| 情况 | 按键 | 断点 |
|---|---|---|
| 这页**没讲完**，下次重讲 | <kbd>S</kbd> | = 当前页 |
| 这页**讲完了**，下次往下 | <kbd>Shift</kbd>+<kbd>S</kbd> | = 当前页 + 1 |

### 看整体进度

<kbd>Esc</kbd> 打开总览：**灰色 = 已讲，橙框 +「▶继续」= 断点**。顶部可切换班级，看别的班讲到哪了。

### 全部快捷键

| 键 | 作用 |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> / 空格 / 滚轮 | 翻页 |
| <kbd>S</kbd> / <kbd>Shift+S</kbd> | 记断点 |
| <kbd>Esc</kbd> | 总览 |
| <kbd>N</kbd> | 写备注（可增删改，可选「全课程」或「仅本班」） |
| <kbd>C</kbd> | 切换班级 |
| <kbd>H</kbd> | 隐藏界面，全屏讲课时用 |

## 五、班级怎么自定义

三种方式，随便用哪个：

1. **转的时候指定**：`--classes "导演2601,导演2602,网新2601"`
2. **写在 config.json 里**：批量转换时所有讲次共用
3. **在网页里直接改**：按 <kbd>C</kbd> 打开面板 —— 双击改名字，点 **×** 删除，点 **＋** 添加

班级数量没有限制，页面里加几个都行。

## 六、换电脑怎么办

进度存在浏览器的 localStorage 里，**只在这台电脑的这个浏览器有效**。跨设备用这两招：

**① 复制网址（最省事）**
点顶栏「备份」→ 选取消，网址被复制到剪贴板。这个网址**自带进度**，存成书签，在任意设备打开都是最新进度（网址里的数字每次记录都会自动更新）。

**② 导出 / 导入文件**
「备份」→ 确定 = 导出 json（含所有班进度 + 备注）；换电脑用「导入」恢复。

> 少数电脑（如 Firefox 打开本地文件）会禁掉 localStorage，页面会提示你，这时用第①招照样能讲课。

## 七、还原度与限制

自动转换**不是像素级复刻**，保真度大约 85–95%：

| 元素 | 情况 |
|---|---|
| 纯色文本、色块、图片 | 基本一致，坐标 100% 还原 |
| 表格 | 行列内容都对，边框粗细可能有细微差别 |
| 渐变填充 | 降级为首个色标的纯色 |
| 艺术字 / 阴影 / 三维 | 降级为纯文本 |
| SmartArt / 图表 / 公式 | 差，建议改用图片 |

每次转换会打印需要人工核对的页码（有表格、渐变、疑似文字溢出的页面），对着原 PPT 扫一眼就行。

## 八、目录结构

```
pptx-progress-deck/
├─ convert.py              主入口（单个 / 批量转换）
├─ config.example.json     配置模板
├─ requirements.txt
├─ tools/
│  ├─ pptx2html.py         pptx → 中间层 JSON
│  ├─ render.py            JSON + 模板 → 单文件网页
│  ├─ deck_template.html   网页外壳 + 断点系统（全部功能都在这里）
│  └─ selftest.py          浏览器端自测（需要 playwright）
├─ api_push.py            受限网络下用 Git Data API 推送（保留提交历史）
├─ examples/               界面截图
└─ build/                  中间层 JSON（转换时自动生成，可在里面微调坐标后重新渲染）
```

想改界面或加功能，基本只需要动 `tools/deck_template.html`。

## 九、自测

```bash
pip install playwright && playwright install chromium
python3 tools/selftest.py
```

会跑 34 项检查：渲染、翻页、断点、刷新恢复、URL 还原、备注增删改、总览标记等。

## 十、常见疑问

**Q：一份课件能支持多少个班？**
A：不限。默认 8 个只是占位，config 里写几个就是几个，网页里也能随时加减。

**Q：多个班共用一份 HTML 会串吗？**
A：不会。进度是按班级 id 分开存的，切换班级时断点、总览标记都跟着变。

**Q：一门课十几个讲次，要开十几个文件吗？**
A：是的，每个讲次一个 HTML。但它们共享同一份班级配置和进度，顶栏下拉可互相跳转。

**Q：能离线用吗？**
A：能，完全离线。单个 HTML 文件，无 CDN 依赖、无网络字体，拷 U 盘就能讲。
